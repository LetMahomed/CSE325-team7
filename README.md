# Remy's Recipes

A .NET Blazor web application for saving recipes, planning meals, and generating grocery lists. Inspired by the spirit of Ratatouille: "Anyone can cook!"

## Team Members

- Adam Cottam
- Christina Lane

## Getting Started

### Prerequisites

- [.NET SDK](https://dotnet.microsoft.com/download) (8.0 or later)

### Run the App

```bash
dotnet run
```

Then open your browser to the URL shown in the terminal (typically `http://localhost:5000`).

## Features

- Add, edit, and delete recipes
- Search recipes by keyword
- Filter recipes by category
- Generate shopping lists from recipe ingredients
- Check off items on shopping list
- Local storage (no account required)

## Tech Stack

- .NET Blazor Server
- SQLite (local database)
- Bootstrap CSS
